# llms.txt

Two plain-text files at the root of this site are written for AI agents and other programs that read documentation:

```{raw} html
<ul class="ot-files">
  <li><a href="../llms.txt"><code>llms.txt</code></a>: a one-paragraph summary of Orthonym and a list of every page.</li>
  <li><a href="../llms-full.txt"><code>llms-full.txt</code></a>: the whole text of the site in one file, with the docstrings of the Python API.</li>
</ul>
```

Both are generated from the Markdown sources of this site every time it is built, so they say what the pages say.
